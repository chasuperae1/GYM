# 🏋️ 健身追踪器

记录训练与饮食的智能助手，支持自动同步到 GitHub。

## 功能

### 1. 训练记录
- 记录每次训练的动作、重量、次数、RPE
- 自动计算训练容量
- 支持自定义动作

### 2. 饮食记录
- 快速记录每餐吃了什么
- 自动计算碳水、蛋白质、脂肪、热量
- 根据时间自动判断餐次（早餐/午餐/晚餐/宵夜）

### 3. 营养统计
- 查看每日营养摄入
- 追踪饮食趋势

### 4. 自动同步
- 每次记录后自动同步到 GitHub
- 数据永不丢失

## 命令

| 命令 | 功能 |
|------|------|
| `开始今天训练` | 开始记录训练 |
| `训练结束` | 结束训练并同步 |
| `我吃了XX` | 快速记录饮食 |
| `记录饮食` | 开始饮食记录模式 |
| `今日饮食` | 查看今日营养摄入 |
| `完成` | 结束饮食记录 |

## 饮食记录格式

```
我吃了 食物名XX克 食物名XX克
```

示例：
```
我吃了 鸡胸肉100克 米饭200克
```

## 预置食物库

- **主食**：白米饭、糙米饭、燕麦、全麦面包、红薯、玉米、土豆
- **蛋白质**：鸡胸肉、瘦牛肉、鱼肉、虾、鸡蛋、豆腐、蛋白粉
- **蔬菜**：西兰花、菠菜、黄瓜、番茄、生菜
- **水果**：苹果、香蕉、蓝莓、橙子
- **油脂**：橄榄油、牛油果、坚果、花生酱

## 自动餐次判断

| 时间 | 餐次 |
|------|------|
| 06:00-10:00 | 早餐 |
| 10:00-14:00 | 午餐 |
| 14:00-18:00 | 下午茶 |
| 18:00-22:00 | 晚餐 |
| 其他时间 | 宵夜 |

## 安装

将整个项目导入到你的工作区，数据库文件 `fitness.db` 会自动创建。

## 数据存储

所有数据存储在 `fitness.db`（SQLite 数据库），包含：
- 训练记录（动作、重量、次数、RPE）
- 饮食记录（食物、份量、营养成分）
- 身体数据（体重、围度）
